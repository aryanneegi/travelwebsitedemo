# 🌍 Travel Website Demo

A modern and responsive Travel Website built to showcase popular destinations, travel packages, and tourism services. The website provides an engaging user experience with attractive visuals, smooth navigation, and a clean interface designed for travelers and adventure enthusiasts.

## 🚀 Features

- 🏖️ Explore popular travel destinations
- 📍 Destination details and highlights
- 🎒 Travel package showcase
- 📱 Fully responsive design
- 🎨 Modern and attractive user interface
- ⚡ Fast and lightweight performance
- 🧭 Easy navigation across sections
- 📷 Beautiful travel imagery and layouts

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/travel-website-demo.git
```

2. Navigate to the project folder

```bash
cd travel-website-demo
```

3. Open `index.html` in your browser or run using Live Server.
